## 一、迁移前置说明
本文档适配基于 Firefly 主题的 Astro 静态博客，完整覆盖 **Twikoo → Waline** 评论迁移全流程，解决两大高频痛点：
1. Waline 后台导入提示成功，但前台页面完全不显示评论；
2. 转换后字段缺失、结构不标准，导入后数据库无数据。

### 前置准备清单
1. 已部署完成 Waline 服务（示例地址：`https://waline.fqzlr.com`）；
2. Firefly 博客页面已挂载 Waline 前端评论组件；
3. 可正常登录 Twikoo 后台导出原始评论 JSON；
4. 浏览器推荐 Chrome / Edge，避免下载、解析兼容问题。

## 二、第一步：导出 Twikoo 原始评论数据
1. 进入你的 Twikoo 管理后台页面；
2. 找到「数据导出」功能，导出全部评论文件；
3. 导出结果为**纯 JSON 数组**，复制全部内容或保存本地 `.json` 文件备用。

## 三、第二步：Twikoo → Waline 专用转换工具（自动修复路径尾斜杠）
### 工具核心能力
> [!IMPORTANT]
> 普通转换工具会丢失 `createdAt`、`user_id` 等必填字段，且路径无尾斜杠导致前台匹配失败，本工具针对性修复：
> 1. 1:1 对齐 Waline 数据表完整字段，补齐所有缺失数据库字段；
> 2. 自动给所有页面路径 `url` 末尾追加 `/`，和 Firefly 前台新建评论格式统一；
> 3. 支持本地 JSON 文件上传、批量替换博客页面路由前缀；
> 4. 修复浏览器点击下载无响应、中文/富文本乱码问题；
> 5. 输出 Waline 官方标准导入外层结构（包含 `Comment/Counter/Users` 三表）。

const $ = s => document.querySelector(s)
const inputEl = $('#input')
const outputEl = $('#output')
const msgEl = $('#msg')
const uploadBtn = $('#uploadBtn')
const convertBtn = $('#convertBtn')
const downloadBtn = $('#downloadBtn')
const clearBtn = $('#clearBtn')
const fixUrlBtn = $('#fixUrlBtn')
const oldUrlInput = $('#oldUrl')
const newUrlInput = $('#newUrl')
const fileInput = $('#fileInput')
let walineJson = null

// 文件上传
uploadBtn.onclick = () => fileInput.click()
fileInput.onchange = async e => {
  const f = e.target.files[0]
  if(!f) return
  inputEl.value = await f.text()
  msgEl.textContent = `已加载文件：${f.name}`
  msgEl.className = 'tip success'
}

// 清空
clearBtn.onclick = () => {
  inputEl.value = outputEl.value = ''
  walineJson = null
  downloadBtn.disabled = true
  msgEl.textContent = ''
  oldUrlInput.value = newUrlInput.value = ''
}

// 标准时间格式化：保留末尾Z，完全匹配你的样本格式
function formatISO(ts) {
  if (!ts || isNaN(Number(ts))) return new Date().toISOString()
  const date = new Date(Number(ts))
  if (isNaN(date.getTime())) return new Date().toISOString()
  return date.toISOString()
}

// 自动标准化url：末尾强制加斜杠，根路径/不重复
function normalizeUrl(path) {
  let url = path?.trim() || '/'
  if (url === '/') return url
  if (!url.endsWith('/')) {
    url += '/'
  }
  return url
}

// 批量替换url路径（解决前台看不到评论）
fixUrlBtn.onclick = () => {
  if (!walineJson) {
    msgEl.textContent = '请先转换数据再替换路径'
    msgEl.className = 'tip error'
    return
  }
  const oldPre = oldUrlInput.value.trim()
  const newPre = newUrlInput.value.trim()
  if (!oldPre || !newPre) {
    msgEl.textContent = '请填写原路径和新路径前缀'
    msgEl.className = 'tip error'
    return
  }
  let count = 0
  walineJson.data.Comment.forEach(item => {
    if (item.url.includes(oldPre)) {
      item.url = item.url.replace(oldPre, newPre)
      // 替换后再次标准化补斜杠
      item.url = normalizeUrl(item.url)
      count++
    }
  })
  outputEl.value = JSON.stringify(walineJson, null, 2)
  msgEl.textContent = `路径替换完成，共修改${count}条评论url`
  msgEl.className = 'tip success'
}

// 核心转换逻辑（严格对齐你提供的真实单条评论结构 + 自动补尾斜杠）
convertBtn.onclick = () => {
  try {
    const raw = inputEl.value.trim()
    if (!raw) throw '输入内容不能为空'
    const twikooList = JSON.parse(raw)
    if (!Array.isArray(twikooList)) throw 'Twikoo导出数据必须是数组格式'

    // 自增objectId，统一数字类型，和你样本一致
    let idSeq = 1
    const commentArr = twikooList.map(tk => {
      // 状态映射
      let status = 'approved'
      if (tk.isSpam === 1) status = 'spam'
      // 评论内容兜底，禁止空值
      const comment = tk.comment?.trim() || '无评论内容'
      // 空回复ID统一为null
      const pid = tk.pid || null
      const rid = tk.rid || null
      // 关键修改：调用标准化函数自动补末尾斜杠
      const url = normalizeUrl(tk.url)
      const insertedAt = formatISO(tk.created)
      const updatedAt = formatISO(tk.updated)
      const createdAt = insertedAt // 同步createdAt字段，缺失会导入丢失
      // 置顶处理：无置顶为null，匹配样本
      const sticky = tk.top ? 1 : null

      const item = {
        user_id: 1,
        objectId: idSeq++,
        nick: tk.nick || '访客',
        mail: tk.mail || '',
        link: tk.link || '',
        ua: tk.ua || '',
        ip: tk.ip || '',
        url,
        comment,
        pid,
        rid,
        sticky,
        status,
        like: null,
        insertedAt,
        createdAt,
        updatedAt
      }
      return item
    })

    // Waline标准外层导出结构
    walineJson = {
      "type": "waline",
      "version": 1,
      "time": Date.now(),
      "tables": ["Comment", "Counter", "Users"],

### 转换工具操作步骤
1. 打开 `twikoo-to-waline.html`；
2. 导入原始 Twikoo 数据，二选一：
   - 方式1：直接粘贴 Twikoo 完整 JSON 数组到上方输入框；
   - 方式2：点击「上传本地JSON」，选中导出的 Twikoo 文件；
3. （可选）博客路由变更批量替换：
   - 旧路径前缀：填写 Twikoo 旧路由，例：`/posts/old/`
   - 新路径前缀：填写当前 Firefly 博客路由，例：`/posts/new/`
   - 点击「一键替换全部url」批量修改所有评论页面地址；
4. 点击「开始转换」；
5. 下方预览框生成标准 Waline 导入 JSON，任意一条评论可查看 `"url": "/xxx/"` 已自动追加尾斜杠；
6. 点击「下载waline-import.json」保存转换文件。

## 四、第三步：Waline 后台导入转换后的评论文件
1. 访问 Waline 管理后台：`https://waline.fqzlr.com/ui`；
2. 左侧菜单栏打开「导入导出」页面；
3. > [!WARNING]
    导入会覆盖现有评论，**务必先导出当前评论备份**，防止数据丢失；
4. 上传刚下载的 `waline-import.json`，点击执行导入；
5. 导入完成后，`Ctrl + F5` 强制刷新后台页面，即可在评论列表看到全部迁移历史评论。

## 五、第四步：Firefly 博客前台验证评论展示
### 匹配原理
转换工具已自动为所有评论 `url` 末尾添加 `/`，和 Firefly 前台手动提交评论的路径格式完全一致，Waline 采用精确字符串匹配，无需修改前端代码。
1. 打开博客对应页面，示例：`fqzlr.com/friends/`；
2. `Ctrl + F5` 强制清除浏览器缓存刷新页面；
3. 页面正常加载全部迁移完成的历史评论。

### 前台无评论排查方案
1. F12 打开浏览器开发者工具，切换到 Network 面板；
2. 筛选 Waline API 请求，查看请求参数 `path` 是否为带尾斜杠格式（`/friends/`）；
3. 核对 Waline 数据库评论 `url` 字段是否和页面路径完全一致；
4. 确认导入流程无报错、未清空原有评论数据。

## 六、高频踩坑问题汇总
### 坑1：导入成功，后台可见评论，Firefly 前台页面空白
- 根因：路径末尾斜杠不匹配（`/friends` vs `/friends/`）；
- 解决方案：使用本文转换工具重新导出带尾斜杠 JSON，清空旧评论后重新导入。

### 坑2：导入提示成功，但 Waline 后台无任何评论
- 原因1：转换 JSON 缺失 `createdAt`/`user_id`/`like` 数据库必填字段；
- 原因2：外层 JSON 结构缺少 `Counter`、`Users` 空数组；
- 解决方案：使用本文完整转换工具，已补齐全部标准字段与外层结构。

### 坑3：转换工具下载按钮点击无响应
- 解决方案：更换 Chrome / Edge 浏览器，关闭浏览器弹窗拦截功能。

### 坑4：评论图片、换行、Emoji 丢失乱码
- 解决方案：工具内置 UTF-8 编码处理，完整保留原始 HTML 富文本内容，无需额外处理。

## 七、兜底备用方案（后台导入解析失败时）
若 Waline 后台导入接口持续丢失数据，可直接写入数据库绕过解析器：
1. 打开转换后的 `waline-import.json`，复制 `data.Comment` 数组内全部评论对象；
2. 进入数据库管理面板（MySQL / SQLite / LeanCloud）；
3. 找到 `wl_Comment` 数据表，批量插入复制的评论数组；
4. 直接写入数据库不会丢失任何评论数据。
